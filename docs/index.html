Why it matters

Technology should adapt
to the person using it.

Starting music often means finding a phone, unlocking it, opening an app, and navigating a screen. A physical tag reduces that sequence to one understandable action.

That can make music easier to share with children, older adults, guests, or anyone who prefers tangible controls. The object can carry meaning—a photo, a color, a handwritten label—not just a technical identifier.

✳ One object.
One clear action. less screen, less friction

Where the project is today

An accessible idea.
A DIY build.

TapTune is working open-source software, but it is not yet a ready-made appliance. Building the current version still requires preparing a Raspberry Pi, connecting a PN532 reader, configuring Python and Spotify, and assembling the physical setup.

The goal is to make this technology easier to access for people who cannot do that work themselves. The repository is the foundation: a transparent implementation that makers can build today and improve toward a simpler future.
