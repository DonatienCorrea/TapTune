Pourquoi c’est utile

La technologie doit s’adapter
à la personne qui l’utilise.

Lancer de la musique demande souvent de trouver un téléphone, le déverrouiller, ouvrir une application et parcourir un écran. Un tag physique réduit cette séquence à une action compréhensible.

La musique devient ainsi plus simple à partager avec les enfants, les personnes âgées, les invités ou toute personne préférant des commandes tangibles. L’objet peut avoir du sens : une photo, une couleur ou une étiquette manuscrite.

✳ Un objet.
Une action claire. moins d’écran, moins de friction

Où en est le projet

Une idée accessible.
Un montage DIY.

TapTune est un logiciel open source fonctionnel, mais pas encore un appareil prêt à l’emploi. La version actuelle demande de préparer un Raspberry Pi, connecter un PN532, configurer Python et Spotify puis assembler le dispositif.

L’objectif est de rendre cette technologie accessible aux personnes qui ne peuvent pas réaliser ce travail elles-mêmes. Le dépôt constitue la base : une implémentation transparente que les makers peuvent construire et simplifier.
